# Blueprint runtime coverage

The Block Library lists actions, typed getters, and property writes by system. Search by the display name, property ID, or system. Drag actions to an event, function, or nested branch. Existing blocks can move between stacks when declarations and control flow remain valid. Drag a getter onto a compatible value slot. You can also click a getter and then activate a highlighted slot, or choose **Insert getter** inside a slot. The block menu includes keyboard-accessible move commands. Undo and Redo cover these edits.

Property tiles default to **Self**. Select **Entity expression** for a scene entity, a parent reference, a prefab result, or another entity expression. Sprite and audio properties accept typed asset references. Bounds and field types are checked before runtime writes. Older blocks, expressions, and project files remain readable.

## Property and operation inventory

| System                       | Runtime reads and writes                                                                                                                                                                                                                                   | Authored fields and lifecycle                                                                                                                                                                                                               |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Variables                    | Read local, instance, parameter, and event payload values with **Get Variable**. Declare locals, assign compatible local or instance variables, and read or write globals.                                                                                 | Blueprint signatures, variable types, exposed overrides, and attachment order determine compile-time scope.                                                                                                                                 |
| Entities and prefabs         | Read identity, membership, parent, persistence, component presence, and world position. Set name, visibility, and draw order. Find an entity by name, instantiate a prefab into an entity variable, or destroy an entity tree.                             | Stable IDs and prefab provenance are read-only. Parent and render-layer assignment, components, and persistence policy are authored to keep hierarchy, residency, and bodies consistent. Spawn and destroy commit at a simulation boundary. |
| Transforms                   | Read and set X, Y, rotation, scale, width, height, and opacity.                                                                                                                                                                                            | World position is derived from the current hierarchy.                                                                                                                                                                                       |
| Visuals and sprites          | Read visual kind, color, text, font size, screen space, image asset, and source-frame values where supported. Clear a sprite's base frame or set applicable visual fields and sprite image and frame values. Read the rendered animation frame separately. | Visual kind and clip definitions are authored because switching visual components or clip tracks changes runtime bindings.                                                                                                                  |
| Physics                      | Read and set body kind, collider size and offsets, live velocity, gravity scale, bounce, and scene gravity. Apply an impulse or move through the collision world.                                                                                          | Contact signal assignments are authored IDs. **Contact Entered** and **Contact Exited** deliver the other entity when available.                                                                                                            |
| Tilemaps                     | Read cell presence, color, terrain, solidity and cost. Paint a color or an authored terrain, erase cells, read layer and terrain settings, and set layer visibility, opacity, collision and navigation.                                                    | Map dimensions, tile size, render-layer linkage, terrain definitions and atlas layout are authored because edits replace the grid or atlas. **Tile Changed** delivers cell coordinates.                                                     |
| Particles                    | Read live emission status and count. Set rate, burst count, limit, lifetime, sizes, angle, spread, speed, gravity, color and seed. Burst, start, or stop a target emitter.                                                                                 | Live count is derived from the particle pool.                                                                                                                                                                                               |
| Lights                       | Read and set point-light enablement, radius, intensity and color, plus scene lighting enablement and ambient color.                                                                                                                                        | Render-layer membership follows the entity.                                                                                                                                                                                                 |
| Cameras                      | Read active view and scene camera settings. Set scene view, follow target, offsets and damping. Read and set camera-component enablement, zoom and damping.                                                                                                | Scene dead zone and bounds are readable. Bounds and dead-zone definitions are authored geometry.                                                                                                                                            |
| Navigation                   | Read and set target, goal, speed and enablement. Read remaining path points or set a world-space goal.                                                                                                                                                     | Path geometry is computed from the live world. **Navigation Arrived** fires on the target agent.                                                                                                                                            |
| Animation and tweens         | Read current state, clip, elapsed time, clip count and parameters. Play a target clip, set parameters, tween motion properties, and read, play, stop or seek timelines.                                                                                    | Animator graphs, transitions, clip frames, timeline keyframes, looping and autoplay are authored. **Animation State Changed** delivers the new state ID.                                                                                    |
| Audio                        | Read and change the entity sound, start or stop playback, read clip settings and playback requests, and read or change the gain and mute state of Master and individual buses.                                                                             | A playback request records game intent. The browser audio engine owns voice completion and output-device state. Clip source, clip routing and synthesis/tracker authoring are asset definitions. Entity autoplay is read-only during play.  |
| Interface                    | Read widget text, enabled, visible, available and typed control values. Set live text, enabled, visible, value and focus. Show, hide, push, pop, replace or move screens and switch themes. Check whether a screen is open.                                | Layout, hierarchy, skins, focus links and layer order are authored assets. Widget signals carry compatible values. **Screen Changed** reports explicit screen control.                                                                      |
| Scene Flow                   | Read active and loaded status, project view dimensions and scene background. Set background and invoke change, add, unload, reload or preload, or follow a named route.                                                                                    | Route definitions and layer structure are authored. Scene entered, exited, loaded and unloaded events deliver stable document IDs.                                                                                                          |
| Behavior Trees               | Read and write typed blackboard keys on a target entity. Read the assigned tree reference.                                                                                                                                                                 | Tree definitions and node policies are authored. Node status is exposed in the Behavior Tree debugger.                                                                                                                                      |
| Data, saves and localization | Read globals, resources, sheet rows, translations, current locale and save-slot availability. Write mutable globals, save or load a slot, and switch languages.                                                                                            | Data schemas, save migrations and translation entries are authored definitions.                                                                                                                                                             |
| Input                        | Read axes and held keys. Use **Key Pressed** and **Key Released** with a physical key code.                                                                                                                                                                | Input bindings are authored project settings.                                                                                                                                                                                               |
| Extensions                   | Call installed typed extension expressions and populate their argument slots.                                                                                                                                                                              | Installing extensions and editing manifests are editor actions. Gameplay never installs or evaluates new extension source.                                                                                                                  |

Component IDs and compiler signatures are defined in the shared [runtime catalog](../packages/blueprints/src/runtime-catalog.ts). The transform inspector consumes the same field names and bounds. Runtime mutations are session state. Project save continues to serialize the authored project.
